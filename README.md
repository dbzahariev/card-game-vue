# Card Game · Vue

Начален проект с Vue 3 и Vite. Началната страница показва голям **Hello world** в центъра на екрана с адаптивна тъмнозелена визия.

## Изисквания

Node.js 20.19+ или 22.12+ и npm.

## Стартиране

```sh
npm install
npm run dev
```

Отвори адреса, който Vite показва в терминала (обикновено http://localhost:5173).
В Windows PowerShell, ако изпълнението на скриптове е ограничено, използвай `npm.cmd` вместо `npm`.

## Production build

```sh
npm run build
npm run preview
```

Готовите файлове се създават в `dist/`.

## Структура

- `src/App.vue` — начална страница.
- `src/style.css` — адаптивна визия.
- `src/main.js` — входна точка на приложението.
- `vite.config.js` — Vite конфигурация.
